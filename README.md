# 🛒 Auchan

Welcome to **Alphanich**!

Auchan is an e-commerce project that I worked on during Sprint II at YouCode. I created this project to practice HTML, Tailwind CSS and JavaScript by building a simple shopping website.

## About the Project

The idea of this project is to create a website where users can browse products, search for what they need, filter products by category and add products to their shopping cart.

While working on this project, I learned how to make a website more dynamic using JavaScript.

## Features

- Display products dynamically from a JSON file.
- Search for products by name.
- Filter products by category.
- Navigate between product pages using pagination.
- Switch between grid and list views.
- Drag and drop products into the cart.
- Add and remove products from the cart.
- Increase and decrease product quantities.
- Calculate the total price.
- Save cart data using LocalStorage.

## How to Run the Project

1. Clone this repository:

```bash
git clone https://github.com/jamal7-codes/auchan-e-commerce-4
```

2. Open the project in VS Code.
3. Install the Live Server extension.
4. Open `index.html`.
5. Right-click and choose **Open with Live Server**.

That's it! The project will open in your browser.
